# GeomPype

**One Python-scripted geometry for both COMSOL simulations and lithography GDS masks.**

GeomPype builds planar drawings, their transformations and their connections.
Layers choose the COMSOL and GDS outputs independently. The
[illustrated library](LIBRARY.md) provides ready-to-use alignment marks and
wafer outlines.

Start with [installation](ENVIRONMENT.md) and your
[first drawing](guide.md#installation-and-first-drawing). GDS-only examples
run without a COMSOL server.
